📊 Project Overview
A comprehensive Power BI dashboard solution for analyzing and optimizing hospital emergency room operations. This project transforms raw ER data into actionable insights to improve patient care, reduce wait times, and enhance operational efficiency.

🎯 Project Objectives
Monitor real-time and historical ER performance metrics

Identify trends in patient volume, wait times, and satisfaction

Enable data-driven decision making for hospital management

Provide granular patient-level analysis capabilities

📋 Dashboard Structure
Dashboard 1: Suummary View
Objective: Holistic performance summary for customizable date ranges

Aggregated metrics from Monthly View

Flexible date filtering for trend analysis

Cross-metric correlation insights

Dashboard 2: Monthly View

Objective: Track monthly performance trends and identify improvement areas

Key Visualizations:

Patient Admission Status (Admitted vs. Non-admitted)

Patient Age Distribution (10-year intervals)

Department Referral Trends

Timeliness Metrics (% seen within 30 minutes)

Gender Distribution Analysis

Racial Demographics Breakdown

Patient Volume by Day and Hour




Dashboard 3: Patient Details
Objective: Granular patient-level data analysis

Data Grid Includes:

Patient ID

Full Name

Gender

Age

Admission Date

Race

Wait Time

Department Referral

Admission Status

Key Performance Indicators (KPIs)
Number of Patients – Daily patient volume with trend analysis

Average Wait Time – Daily fluctuations and bottleneck identification

Patient Satisfaction Score – Service quality tracking

Number of Patients Referred – Department referral patterns
